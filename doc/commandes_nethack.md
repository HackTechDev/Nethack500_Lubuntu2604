# Principales commandes de NetHack

## Déplacement

| Touche | Action |
|---|---|
| `h` `j` `k` `l` | Gauche, bas, haut, droite |
| `y` `u` `b` `n` | Diagonales (haut-gauche, haut-droite, bas-gauche, bas-droite) |
| `Maj` + direction | Courir dans une direction |
| `<` / `>` | Monter / descendre un escalier |
| `_` | Voyager vers un point de la carte |
| `s` | Fouiller (passages secrets) |
| `.` | Attendre un tour |

## Objets et inventaire

| Touche | Action |
|---|---|
| `i` | Afficher l'inventaire |
| `,` | Ramasser |
| `d` / `D` | Poser un objet / plusieurs objets |
| `w` | Manier une arme |
| `x` | Échanger arme principale et secondaire |
| `W` / `T` | Porter / retirer une armure |
| `P` / `R` | Mettre / retirer un accessoire (anneau, amulette, bandeau) |
| `q` | Boire (*quaff*) |
| `r` | Lire un parchemin ou un livre |
| `e` | Manger |
| `z` | Utiliser une baguette (*zap*) |
| `a` | Appliquer / utiliser un outil |
| `t` | Lancer un objet |
| `f` | Tirer (carquois) |
| `Q` | Remplir le carquois |
| `#name` (`C`) | Nommer un objet ou un monstre |

## Actions

| Touche | Action |
|---|---|
| `F` + direction | Combattre (forcer l'attaque) |
| `Z` | Lancer un sort |
| `+` | Liste des sorts connus |
| `o` / `c` | Ouvrir / fermer une porte |
| `Ctrl+D` | Donner un coup de pied |
| `#pray` (`Alt+p`) | Prier |
| `#offer` | Sacrifier sur un autel |
| `#chat` | Parler |
| `#loot` | Fouiller un conteneur au sol |
| `#force` | Forcer une serrure |
| `#enhance` | Améliorer ses compétences |

## Informations

| Touche | Action |
|---|---|
| `:` | Regarder ce qui est au sol |
| `;` | Identifier un symbole sur la carte |
| `^` | Identifier un piège adjacent |
| `Ctrl+X` | Attributs du personnage |
| `Ctrl+O` | Vue d'ensemble du donjon |
| `Ctrl+P` | Messages précédents |
| `\` | Objets découverts |
| `?` | Aide |

## Partie

| Touche | Action |
|---|---|
| `S` | Sauvegarder et quitter |
| `O` | Options |
| `#quit` | Abandonner la partie |

## Mode wizard (`nethack -D`)

| Touche | Action |
|---|---|
| `Ctrl+F` | Cartographier le niveau |
| `Ctrl+W` | Faire un vœu |
| `Ctrl+V` | Téléportation de niveau (`?` pour le menu) |
| `Ctrl+T` | Téléportation sur le niveau |
| `Ctrl+I` | Identifier tout l'inventaire |
| `Ctrl+G` | Créer un monstre |
| `Ctrl+E` | Détecter portes et passages secrets |

> **Note :** ces touches correspondent à la configuration par défaut. Avec l'option `number_pad` activée, le déplacement passe sur le pavé numérique et certaines touches changent (par exemple `k` devient le coup de pied).
